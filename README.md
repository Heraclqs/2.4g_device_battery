# 2.4G 设备电量

在 Windows 上读 2.4G 鼠标和键盘电量。不安装第三方包，只用 Python 标准库和 `ctypes`。

已经接上的是多彩 M900 Mini Pro+、狼蛛 L3、英菲克（网页驱动里的 X3、IN10R 等型号）、ATK F1 和 ATK V75X。

## 运行

```bat
python my_devices.py --once
python my_devices.py
pythonw start_tray.pyw
```

`--once` 只打印已经连上、并且回了电量的设备。接收器还插着、但鼠标或键盘没连上时，主页留空，不会把休眠或离线显示成一块设备卡片。

不带参数会打开面板。主页是每台已连接设备的产品图、电量和当前状态。设置页改刷新间隔、开机自启、低电量弹窗和 DPI 档位变化弹窗。电量在 60% 及以上是绿色，中等是黄色，到达低电量线是红色。多彩还能看到电压。多台同时在线时，托盘图标用其中最低的电量。

低电量默认在 20% 及以下、并且没有充电时，用 Windows 通知提醒一次，之后每再降 5% 再提醒。狼蛛 L3、ATK F1、英菲克和多彩醒着时会持续听 DPI 档位，一切换就弹出，不用等电量刷新。

托盘图标就是电量数字。左键立刻再读一次，右键打开面板。悬停可以看到设备名、电量和更新时间。刷新由系统计时器驱动，默认 60 秒，设置里可以改成 30 秒到 30 分钟。空闲时不会循环读设备。

设置里的「开机自启」会在「启动」文件夹放一个叫「电量托盘」的快捷方式，目标是 `pythonw.exe`，任务管理器的「启动」页可以直接禁用它。托盘本身不会改这个快捷方式。

「放到桌面」会放一个指向本目录的目录链接，以及一个指向 `start_tray.pyw` 的文件链接。没有符号链接权限时，目录改用联接；文件如果跨盘符，会改成快捷方式。

加 `--debug` 时，读数过程打在控制台上。程序不写日志文件。设置放在 `%APPDATA%\2.4gDeviceBattery\config.json`。

## 这台鼠标

接收器显示为 Compx `DELUX-1K Dongle`，`3554:FB23`。电量在 Usage Page `0xFF02` / Usage `0x0002` 的 17 字节报告里。报文格式、校验和这台机器上的一次实测写在 [PROTOCOL.md](PROTOCOL.md)。

读的时候如果鼠标正在休眠，面板会提示动一下鼠标，不会把缺少回包显示成 0%。

## 狼蛛 L3

接收器是 YJX `USB Receiver`，`A8A5:2255`（有线鼠标是 `A8A4:2255`）。电量在 Usage Page `0xFF01` / Usage `0x0010` 的 64 字节帧里，命令 `0x30`。这套帧和狼蛛网页驱动 `hub.aulacn.com` 的 xxwd 协议一致。报文写在 [PROTOCOL.md](PROTOCOL.md)。

## 英菲克

2.4G 接收器是 `1D57:FA65`（8K，另一只是 `FA60`），产品名 `Inphic KP 8K`。官方客户端开着时，电量从它给网页驱动用的 `ws://localhost:10085` 读。客户端没开时，直接听接收器 Usage Page `0xFF00` 上 Report ID `0x04` 的电量报告。鼠标休眠时没有报告，动一下即可。

## ATK F1

接收器是 `ATK Mouse 1K Dongle`，`373B:101A`（8K 接收器是 `373B:101B`）。电量在 Usage Page `0xFF02` / Usage `0x0002` 的 17 字节报告里，和多彩同一套 Compx 帧。这台机器上的身份回包是 cid `2`、mid `56`，网页驱动 `v3-hub.atkgear.com` 里这是 ATK F1 LEVIATAN。鼠标休眠时接收器不回电量，面板会提示动一下鼠标。

## ATK V75X

接收器是 `ATK V75X 2.4G Dongle`，`320F:5088`（有线是 `320F:5055`）。电量在 Usage Page `0xFF1C` / Usage `0x0092`，Report ID `0x04`，命令 `26`。百分比在载荷第 7 字节，下一字节为 `2` 表示正在充电。键盘休眠时命令字节回来是 `0xFF`，不会显示成 0%。报文写在 [PROTOCOL.md](PROTOCOL.md)。
