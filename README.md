# 2.4G 设备电量

在 Windows 上读多彩 M900 Mini Pro+ 的 2.4G 电量。不安装第三方包，只用 Python 标准库和 `ctypes`。

当前只接了这台已经对过报文的鼠标。ATK F1、英科特 IN10R、狼蛛 L3 和 ATK VXE V75X 还没做。

## 运行

```bat
python my_devices.py --once
python my_devices.py
pythonw start_tray.pyw
```

`--once` 打印一行电量。不带参数会打开简洁面板：大号百分比、颜色（60% 及以上绿色，30% 到 59% 黄色，低于 30% 红色）、充电状态和电压。

托盘图标就是电量数字。左键立刻再读一次，右键打开面板。悬停可以看到设备名、电量和更新时间。刷新由系统计时器驱动，默认 60 秒，面板里可以改成 30 秒到 30 分钟。空闲时不会循环读设备。

面板里的「开机自启」会在「启动」文件夹放一个叫「电量托盘」的快捷方式，目标是 `pythonw.exe`，任务管理器的「启动」页可以直接禁用它。托盘本身不会改这个快捷方式。

「放到桌面」会放一个指向本目录的目录链接，以及一个指向 `start_tray.pyw` 的文件链接。没有符号链接权限时，目录改用联接；文件如果跨盘符，会改成快捷方式。

加 `--debug` 时，读数过程打在控制台上。程序不写日志文件。设置放在 `%APPDATA%\2.4gDeviceBattery\config.json`。

## 这台鼠标

接收器显示为 Compx `DELUX-1K Dongle`，`3554:FB23`。电量在 Usage Page `0xFF02` / Usage `0x0002` 的 17 字节报告里。报文格式、校验和这台机器上的一次实测写在 [PROTOCOL.md](PROTOCOL.md)。

读的时候如果鼠标正在休眠，面板会提示动一下鼠标，不会把缺少回包显示成 0%。
